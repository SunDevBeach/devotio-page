Política de Privacidade - Devotio

Última atualização: 21 de março de 2026

Esta Política de Privacidade descreve como o aplicativo Devotio trata as informações dos usuários, em conformidade com a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 - LGPD).

1. Coleta de Informações

O Devotio não coleta dados pessoais diretamente dos usuários, como nome, e-mail ou qualquer informação de identificação.

O aplicativo funciona majoritariamente de forma offline, utilizando conteúdos armazenados localmente no dispositivo.

No entanto, para funcionalidades específicas, como a obtenção de conteúdos atualizados (ex: liturgia diária), podem ser realizadas requisições a APIs externas. Nessas comunicações, podem ser processados dados técnicos, como:

  • Endereço IP
  • Informações básicas do dispositivo
  • Dados necessários para comunicação com servidores

2. Uso das Informações

As informações técnicas são utilizadas exclusivamente para:

  • Carregar conteúdos atualizados do aplicativo
  • Garantir o funcionamento adequado das funcionalidades

3. Compartilhamento de Dados

O Devotio não vende, aluga ou compartilha dados pessoais dos usuários.

Eventuais dados técnicos podem ser processados por serviços externos apenas para viabilizar o funcionamento do aplicativo.

4. Armazenamento de Dados

O aplicativo não armazena dados pessoais em servidores próprios. Os conteúdos utilizados são armazenados localmente no dispositivo do usuário ou carregados sob demanda.

5. Segurança

São adotadas boas práticas de desenvolvimento para garantir a segurança das informações durante o uso do aplicativo.

6. Direitos do Usuário (LGPD)

Nos termos da LGPD, o usuário pode solicitar informações sobre o tratamento de dados, quando aplicável.

7. Crianças e Adolescentes

O aplicativo não coleta intencionalmente dados pessoais de menores de idade.

8. Alterações nesta Política

Esta política pode ser atualizada a qualquer momento, sendo recomendada sua revisão periódica.
